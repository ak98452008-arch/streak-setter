# Streak Setter

A responsive, installable habit streak tracker by @Ayush9845.

## Run locally
Open `index.html` in a browser. For PWA installation/offline caching, serve this folder over HTTPS (GitHub Pages works).

## Features
- Create, edit, and check off daily habits
- Current streaks, daily progress, and total check-ins
- Monthly activity calendar
- Local browser storage
- Telegram feedback link: https://t.me/Ayush9845

## Data and accounts
This version stores data in the current browser using localStorage. It does not include cloud accounts or cross-device sync; those require a configured backend.
